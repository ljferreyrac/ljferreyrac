### 🧩 What I've Been Building

- 🕸️ **Multi agent pipeline for real time Wi-Fi network analytics** with CrewAI and LangGraph: specialized agents for telemetry analysis, log classification, ping pong detection and sticky client diagnosis
- 🔀 **LLM proxy layer** with dynamic routing between self hosted models (Qwen, DeepSeek, ZGLM) and cloud providers, enabling model swapping and A/B evaluation
- 🔎 **End to end LLM observability** with Phoenix/Arize: tracing MCP client calls, agent sessions and tool executions to find latency bottlenecks and output inconsistencies
- ⚙️ **MCP automation of the developer workflow** integrating JIRA, Confluence and Bitbucket, including automatic PR generation
- 🚦 **Redis based batching layer** that regulated outbound traffic and cut HTTP 429 rate limit errors
- 🔐 **JWT + Azure SSO migration** on a Spring Boot ERP, with a 30% latency reduction through DTO redesign
